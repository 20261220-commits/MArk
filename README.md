# 네모 대륙 1.17

마인크래프트 자바 에디션 1.17(동굴과 절벽 1부)을 최대한 비슷하게 따라 만든 브라우저 복셀 샌드박스 게임입니다.
설치 없이 크롬(크롬북 포함)에서 바로 실행됩니다. 블록·아이템·몹 텍스처는 자유 라이선스 리소스 팩 **Pixel Perfection CE**를 쓰고, 소리는 코드로 합성합니다.

> Mojang/Microsoft와 관계없는 비공식 팬 프로젝트입니다. 원작(Mojang)의 텍스처·소리 파일은 사용하지 않았습니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| **파일 하나로 실행 (오프라인)** | `dist/nemo-1.17.html` 을 내려받아 크롬에서 열면 됩니다. 인터넷이 없어도 동작합니다. |
| **GitHub Pages** | 저장소 설정 → Pages 에서 `main` 브랜치 루트를 켜면 `index.html` 로 바로 플레이할 수 있습니다. |
| **로컬 서버** | `python3 -m http.server` 후 `http://localhost:8000` 접속 |
| **멀티플레이 서버** | `node tools/server.js` (의존성 없음) 후 같은 와이파이의 기기에서 `http://<이 컴퓨터 주소>:8080` 접속. 게임 파일도 함께 제공합니다. |

세계는 브라우저의 IndexedDB에 저장되므로 같은 브라우저에서 이어서 플레이할 수 있습니다.

## 멀티플레이

### 서버 세계 (만든 사람이 없어도 언제든 접속)
- 서버 컴퓨터에서 `node tools/server.js 8080 --world 이름` 을 실행해 두면 세계가 그 컴퓨터의 `worlds/이름/` 에 저장됩니다.
- 처음 접속한 사람이 **새 서버 세계**를 만들거나, 자기 세계에서 Esc → 멀티플레이 열기 → **서버 세계로 올리기** 로 지금 세계를 통째로 올립니다.
- 그다음부터는 누구나 타이틀 → 멀티플레이 → **서버에 접속** 으로 들어옵니다. 각자의 인벤토리·위치·발전 과제는 이름별로 서버에 남습니다.
- 계산(몹, 물·용암, 작물, 레드스톤)은 접속한 사람들이 나눠 맡습니다: 차원마다 그곳에 먼저 있는 사람이 맡고, 그 사람이 나가거나 다른 차원으로 가면 다음 사람이 자동으로 이어받습니다. 그래서 각자 오버월드·네더·엔드에 따로 있어도 됩니다. 아무도 없으면 세계는 저장된 채 기다립니다.
- 시간·날씨는 서버가 돌리고, 오버월드의 모두가 침대에 누우면 밤이 지나갑니다.

### 내 세계를 친구에게 열기

- **여는 사람(호스트)**: 세계에 들어가 Esc → **멀티플레이 열기**. ① **서버로 열기**: `node tools/server.js` 가 알려 주는 주소(`ws://…:8080/mp`)로 엽니다. ② **서버 없이 열기**: **초대 코드 만들기** 를 눌러 나온 코드를 친구에게 보내고, 친구가 돌려준 답장 코드를 넣으면 연결됩니다(WebRTC, 참가자마다 한 번씩).
- **참가하는 사람**: 타이틀 → **멀티플레이** → 같은 서버 주소로 **서버에 접속**, 또는 초대 코드를 붙여 넣고 나온 답장 코드를 호스트에게 보냅니다.
- 함께 되는 것: 같은 세계(시드가 같은 지형 + 호스트가 바꾼 청크를 받아 옴), 블록·문·레버·버튼, 상자·화로·호퍼 등 보관함 내용(화로 굽기 진행 포함), 떨어진 아이템과 경험치 구슬(누가 떨어뜨려도 모두에게 보이고 주울 수 있음), 서로의 모습(스킨·사용자 스킨·든 아이템·갑옷·자세·이름표), 채팅, 시간과 날씨, 몹(가장 가까운 플레이어를 쫓아가 공격·사격, 참가자도 때릴 수 있음). 참가자의 인벤토리·체력·위치는 참가자 기기에 호스트 세계별로 저장되어 다시 들어오면 이어집니다.
- 내 세계를 열어도 서버 세계와 같은 방식으로 돌아갑니다: 차원마다 그곳에 먼저 있는 사람이 계산을 맡으므로, 호스트가 오버월드에 있어도 참가자는 네더·엔드에 따로 갈 수 있습니다. 참가자가 다른 차원에서 바꾼 블록은 호스트 세계에 저장되어, 멀티플레이를 닫은 뒤 혼자 들어가도 남아 있습니다.
- 플레이어끼리: 서로 때리기(PvP — 무기·차징·치명타·날카로움·발화·밀치기, 맞는 쪽 갑옷·방패 적용), 이름이 들어간 사망·발전 과제 메시지, 모두 침대에 누워야 밤이 지남, 참가자가 호스트의 몹에게 하는 먹이 주기·털 깎기·우유 짜기·염색·길들이기·이름표도 공유 세계에서 처리, 참가자가 잡은 몹도 플레이어 처치(경험치·전리품)
- **Tab**: 플레이어 목록(거리·차원), 화면 왼쪽 위 좌표 표시(설정 → 좌표 표시), 이름표는 벽 너머로는 흐리게(웅크리면 숨김)
- 탈것: 보트·광산 수레는 모두에게 보이는 공유 물건이고, 말·당나귀·돼지·스트라이더·보트·수레를 누구나 타고 조종할 수 있습니다(탄 사람이 조종하고 세계가 따라감). 길들이기도 공유됩니다.
- 주민·떠돌이 상인 거래: 거래 목록과 사용 횟수는 그 차원을 맡은 사람의 주민 것이고, 참가자는 자기 아이템으로 거래합니다. 상자·호퍼 달린 광산 수레의 내용물, 말 안장·갑옷도 모두에게 같게 맞춰집니다. 참가자의 `/summon`·`/kill @e` 도 공유 세계의 몹에 적용됩니다.
- 주의: GitHub Pages(https)로 연 게임은 브라우저가 `ws://` 연결을 막습니다. 서버 세계에 접속하려면 `node tools/server.js` 가 알려 주는 `http://…` 주소로 게임을 여세요(초대 코드 방식은 Pages에서도 됩니다).

## 1.17과 같은 부분

- 1.17 광석 분포: 석탄·철·구리(1.17)·금·레드스톤·다이아몬드·청금석·에메랄드(산), 화강암/섬록암/안산암/응회암 덩어리, 흙·자갈 덩어리

- 던전(몬스터 생성기 + 전리품 상자), 참나무·자작나무·가문비나무, 꽃·풀·고사리·사탕수수·선인장·호박·버섯·마른 덤불, 추운 바이옴의 눈과 얼음

**네더**

## 크롬북 최적화

- **Web Worker 멀티스레드**: 지형 생성과 메시 생성을 모두 워커(코어 수에 맞춰 1~3개)에서 처리해 메인 스레드가 끊기지 않습니다.
- **동굴 경로 캐시**: 청크마다 주변 289개 청크의 동굴을 다시 계산하지 않고 한 번 계산한 경로를 재사용합니다 (청크 생성 67ms → 17ms).
- **메셔**: 숨은 면 제거, 위아래까지 패딩한 볼륨에서 인덱스 오프셋으로 이웃·AO를 읽어 청크당 약 5ms.
- **작은 정점 형식**: 정점당 20바이트(Uint16 위치/UV, Uint8 빛/색). 바이옴 색은 텍스처 알파 마스크로 셰이더에서 입혀 텍스처를 늘리지 않습니다.
- **프레임 예산**: 워커 결과는 한 프레임에 쓰는 시간과 GPU 업로드 수를 제한해서 반영하고, 워커는 프레임과 상관없이 계속 일을 받습니다.
- **자동 해상도**: FPS가 40 아래로 떨어지면 렌더 해상도를 낮추고, 여유가 생기면 다시 올립니다.
- 그림자·안티앨리어싱·밉맵 없음, 청크 단위 절두체 컬링, 렌더 거리 밖 엔티티는 그리지 않음.
- **높이 256이어도 가볍게**: 청크마다 가장 높은 블록을 기억해 메시 생성·무작위 틱·데이터 복사를 그 높이까지만 합니다(빈 하늘은 건너뜀).
- **리소스 팩**: PNG를 빌드 때 원시 RGBA로 바꿔 압축해 두고, 실행 시 브라우저 내장 `DecompressionStream`으로 풀어 바로 텍스처에 씁니다(캔버스 읽기 없음). 물·용암·차원문 애니메이션은 아틀라스의 해당 칸만 GPU에서 교체합니다.
- **구조물 생성도 워커에서**: 마을·요새·네더 요새는 시드만으로 결정되는 함수라 청크마다 자기 부분만 찍고, 네더 지형은 4×8×4 격자 노이즈를 보간해 계산량을 줄였습니다.
- **레드스톤**: 가루 회로는 변경이 생긴 연결망만 다시 계산하고, 지연 부품은 예약 틱으로 처리합니다.
- **길찾기 예산**: A\* 탐색은 틱당 2회, 탐색 노드 360개로 제한하고 경로를 재사용합니다.
- **몹 한 마리 = 그리기 1~3번**: 몹 모델을 부위마다 따로 그리지 않고 뼈(skinning) 하나의 메시로 합쳐, 엔더 드래곤도 그리기 호출 40번 → 2번이 되었습니다.
- **저장은 워커에서**: 청크 저장(RLE 압축)을 별도 워커에서 처리해 자동 저장·청크 언로드가 프레임을 멈추지 않습니다.
- **셰이더 미리 컴파일**: 로딩 화면에서 모든 몹 모델과 셰이더를 미리 만들어 처음 보는 몹이 등장할 때 멈칫하지 않습니다.
- 잎 소멸 검사·빛 이어붙이기·메시 버퍼를 할당 없이 처리하고, FPS가 낮을 때는 프레임당 GPU 업로드 수를 줄입니다.
- 권장 설정(크롬북): 렌더 거리 4~6, 그래픽 *빠르게*, 자동 해상도 *켜짐*.

- **client.jar 를 고르면 모든 텍스처가 원작 1.17**: 블록·아이템뿐 아니라 HUD(하트·배고픔·갑옷·공기·경험치 막대·핫바·조준점), 해·달(8가지 위상)·구름·비·눈, 파티클(연기·불꽃·하트·음표·물보라 등, 애니메이션 포함), 그림 26종, 현수막·방패, 인챈트 반짝임(아이콘·손·떨어진 아이템·갑옷), 지도 아이콘과 종이, 효과 아이콘, 갑옷 모델, 화살·경험치 구슬·광산 수레·갑옷 거치대·아이템 액자·표지판·낚시찌까지 jar의 그림을 씁니다. 문·가마솥·양초처럼 원작에서 납작한 아이템 그림을 쓰는 블록 아이템도 그 그림으로 나옵니다. jar 없이 실행하면 Pixel Perfection CE와 직접 그린 대체 그림을 씁니다. 보관함 화면 배경과 글꼴은 아직 HTML 디자인입니다.
- **엔드 시티**: client.jar 를 불러오면 원작 EndCityGenerator 규칙(탑·다리·뚱뚱한 탑·배 한 척, 다른 갈래와 겹치면 버림, 깊이 8)으로 원작 조각을 이어 만들고, 셜커·보물 상자·배의 겉날개 액자가 원작 위치에 생깁니다(구조물을 넣으려면 jar를 다시 한 번 불러와야 함). 삼림 대저택은 아직 직접 짠 방 배치입니다.
- 해저 신전은 원작의 절차적 구성(입구 홀·양 날개의 엘더 가디언 방·방 격자·금 블록 핵심부·옥상 펜트하우스·젖은 스펀지 방)을, 삼림 대저택은 원작의 격자 알고리즘(복도 → 2×2·2×1·1×1 방 채우기 → 복도가 닿지 않는 비밀 방, 위층은 아래층 위에)을, 보루 잔해는 원작의 네 종류(다리·호글린 마구간·보물 방·주거 구역)를 따릅니다. 기본 상태에서 각 방과 보루의 세부 모양은 직접 짠 배치이고, client.jar 를 불러오면 보루 잔해는 원작 구조물 파일로 만들어집니다(아래 리소스 팩 항목). 네더의 폐허가 된 포탈은 원작처럼 절반은 용암 바다 위 발판에, 절반은 무작위 높이에서 찾은 동굴 바닥에 생깁니다. 보루 잔해는 원작처럼 y 33에 생성됩니다.
- 색·재질은 블록 메타데이터에 담습니다(게임 안에서는 별개 블록처럼 보입니다). 블록 ID를 16비트로 늘리기 전에 들어간 피뢰침·무색 양초는 사슬의 변형, 염색한 양초는 카펫의 남는 메타 비트에 그대로 있습니다. 저장 파일에 아이템 ID 표를 함께 기록해서, 아이템이 추가되거나 순서가 바뀌어도 예전 세계의 인벤토리·상자가 그대로 열립니다(8비트 시절 세계도 불러올 수 있음).
- 좀비 말은 원작처럼 명령어로만 나옵니다.
- 블록·아이템·몹 텍스처는 리소스 팩 Pixel Perfection CE(1.16.2 지원)에서 가져옵니다. 팩에 없는 1.17 콘텐츠(구리·자수정·점적석·심층암·양초·무성한 동굴 식물·스컬크 감지기, 염소·아홀로틀·발광 오징어, 망원경 등)와 드래곤 머리·종 몸통 같은 일부만 직접 그린 텍스처를 씁니다. 팩에 없는 텍스처는 새로 그리지 않습니다.
- **설정 → 리소스 팩...** 에서 내 기기에 있는 리소스 팩 .zip 이나 마인크래프트 client.jar 를 고르면 그 텍스처로 바뀝니다(바닐라 1.17 jar를 고르면 구리·자수정·점적석 같은 1.17 블록·아이템도 원작 텍스처가 됨). 파일은 그 브라우저 안에서만 변환·저장되고, 저장소나 배포 파일에는 Mojang 텍스처가 들어 있지 않습니다. 고른 팩에 없는 텍스처는 기본 팩 것을 그대로 씁니다. 염소·아홀로틀(5색)·발광 오징어는 팩에 텍스처가 있으면 원작(자바판) 모델로 바뀝니다.
- **client.jar 의 원작 구조물**: client.jar 를 고르면 그 안의 구조물 파일(NBT)과 상자 전리품 표도 브라우저 안에서 읽어 둡니다. 이후 새로 생성되는 청크부터 마을(평원·사막·사바나·눈 덮인·타이가, 좀비 마을 2%)·약탈자 전초기지·보루 잔해·이글루·난파선·해저 유적·폐허가 된 포탈·화석·네더 화석이 원작 조각과 원작 직소(jigsaw) 조립 규칙(깊이·영역 안에 맞추기·지형 맞춤 조각·종료 조각)으로 만들어지고, 상자에는 원작 전리품 표(내구도·무작위 마법 부여·탐험 지도 포함)가 들어갑니다. 마을 장식 풀의 나무·건초 더미·꽃·선인장·호박 같은 지형 지물도 생깁니다. 이 파일들 역시 저장소나 배포 파일에는 들어 있지 않습니다.

크롬북 윗줄 키는 같은 자리에 있는 PC의 F키로 읽습니다. 검색 키 + 윗줄 키나 크롬북 설정의 "윗줄 키를 기능 키로 사용"으로 보내는 진짜 F키도 그대로 동작합니다. F3 조합(F3이나 새로고침 키를 누른 채로): A 청크 다시 불러오기, B 히트박스, C 위치 복사, D 채팅 지우기, G 청크 경계, H 고급 툴팁(내구도·아이템 ID), N 관전 모드 전환, P 포커스 잃으면 일시 정지, Q 도움말. 설정에서 달리기·웅크리기를 "전환"으로 바꿀 수 있습니다(원작 접근성 설정). 크롬북에서 Ctrl+W는 탭을 닫으므로, Ctrl로 달리려면 설정의 "전체 화면 + 키 잠금"을 켜세요(실수로 닫으려 하면 확인 창이 뜹니다).

터치 화면에서는 왼쪽 조이스틱, 화면 드래그로 시점, 오른쪽 버튼(캐기·놓기·점프·웅크리기)을 사용합니다.
