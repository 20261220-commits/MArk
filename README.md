# 네모 대륙 1.17

마인크래프트 자바 에디션 1.17(동굴과 절벽 1부)을 최대한 비슷하게 따라 만든 브라우저 복셀 샌드박스 게임입니다.
설치 없이 크롬(크롬북 포함)에서 바로 실행됩니다. 블록·아이템·몹 텍스처는 자유 라이선스 리소스 팩 **Pixel Perfection CE**를 쓰고, 소리는 코드로 합성합니다.

> Mojang/Microsoft와 관계없는 비공식 팬 프로젝트입니다. 원작(Mojang)의 텍스처·소리 파일은 사용하지 않았습니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| **파일 하나로 실행 (오프라인)** | `dist/nemo-1.17.html` 을 내려받아 크롬에서 열면 됩니다. 인터넷이 없어도 동작합니다. |
| **GitHub Pages** | 저장소 설정 → Pages 에서 `main` 브랜치 루트를 켜면 `index.html` 로 바로 플레이할 수 있습니다. |
| **로컬 서버** | `python3 -m http.server` 후 `http://localhost:8000` 접속 |

세계는 브라우저의 IndexedDB에 저장되므로 같은 브라우저에서 이어서 플레이할 수 있습니다.

**동굴과 절벽 신규 요소 (추가)**
- **아홀로틀**: 분홍·갈색·금색·청록색 + 희귀한 파란색(번식 시 1/1200). 물속에서 대구·연어·열대어·오징어·드라운드를 사냥하고, 플레이어가 때린 몹을 먼저 노리며, 함께 잡으면 플레이어에게 재생 효과. 다치면 1/3 확률로 죽은 척하며 회복, 물 밖에서는 5분 뒤 말라서 피해(비를 맞으면 괜찮음). 해수면 아래 어두운 물(점토 위)에서 무리로 스폰
- **열대어**와 **아홀로틀 양동이·열대어 양동이**: 물 양동이로 떠 담고, 놓으면 물과 함께 그대로(색 유지) 나옴. 아홀로틀은 열대어 양동이로 번식(빈 물 양동이가 돌아옴)
- **뇌우와 번개**: `/weather thunder`, 비와 별개인 뇌우 주기, 로드된 청크마다 틱당 1/100000 확률의 낙뢰, 번개 줄기와 섬광, 천둥, 주변 5 피해와 화상, 보통·어려움 난이도에서 불, 돼지 → 좀비 피글린. 낮에는 뇌우일 때만 잘 수 있음
- **피뢰침**: 구리 주괴 3개, 6방향 설치, 128블록 안의 낙뢰를 끌어당김(불이 나지 않음), 맞으면 8틱 동안 레드스톤 신호 15, 받치고 있는 구리와 주변 구리의 산화를 되돌림
- **양초**: 무색 + 16색(실 + 꿀벌집 조각, 염료로 염색), 한 칸에 4개까지 쌓기, 부싯돌로 켜고 빈손 우클릭으로 끄기, 켠 양초 개수 × 3의 밝기
- **밀랍칠**: 꿀벌집 조각으로 구리 블록(산화 4단계)과 깎인 구리에 밀랍칠(산화 멈춤, 조합법도 가능), 도끼로 밀랍을 먼저 벗기고 그다음 산화를 벗김

**동굴과 절벽 신규 요소 (2)**
- **자수정 싹**: 싹트는 자수정에서 작은·중간·큰 싹을 거쳐 자수정 군집으로 자람(붙은 면 방향 유지), 군집에서 자수정 조각
- **점적석**: 종유석·석순이 자라고, 물·용암 아래 종유석에서 물방울이 떨어져 아래 **가마솥**을 채움, 종유석은 받침이 없으면 떨어지며 맞은 것에 피해, 석순에 떨어지면 낙하 피해 2배
- **가마솥**: 물·용암·가루눈 양동이로 채우고 비우기, 비·눈으로 채워짐, 유리병으로 물 뜨기, 비교기로 양 측정
- **깎인 구리** 산화 4단계와 반 블록·계단(산화·밀랍칠·벗기기 모두 적용)
- **무성한 동굴**: 진달래·꽃 핀 진달래(나무)·잎, 이끼 카펫, 동굴 덩굴과 **발광 열매**(밝기 14, 먹을 수 있음), 포자 꽃(떠다니는 포자), 큰 흘림잎(올라서면 기울어 떨어짐, 레드스톤으로 고정), 작은 흘림잎, 뿌리 내린 흙, 매달린 뿌리
- **아이템 액자·발광 아이템 액자**: 아이템을 걸고 45°씩 돌리기, 뒤의 비교기가 회전 단계를 읽음, 발광 액자는 아이템을 밝게 표시
- **스컬크 감지기**: 걸음·블록 변화·투사체 등의 진동을 8블록 안에서 감지해 거리에 따른 신호, 양털 위를 걷거나 웅크리면 감지 안 됨

## 크롬북 최적화

- **Web Worker 멀티스레드**: 지형 생성과 메시 생성을 모두 워커(코어 수에 맞춰 1~3개)에서 처리해 메인 스레드가 끊기지 않습니다.
- **동굴 경로 캐시**: 청크마다 주변 289개 청크의 동굴을 다시 계산하지 않고 한 번 계산한 경로를 재사용합니다 (청크 생성 67ms → 17ms).
- **메셔**: 숨은 면 제거, 위아래까지 패딩한 볼륨에서 인덱스 오프셋으로 이웃·AO를 읽어 청크당 약 5ms.
- **작은 정점 형식**: 정점당 20바이트(Uint16 위치/UV, Uint8 빛/색). 바이옴 색은 텍스처 알파 마스크로 셰이더에서 입혀 텍스처를 늘리지 않습니다.
- **프레임 예산**: 워커 결과는 한 프레임에 쓰는 시간과 GPU 업로드 수를 제한해서 반영하고, 워커는 프레임과 상관없이 계속 일을 받습니다.
- **자동 해상도**: FPS가 40 아래로 떨어지면 렌더 해상도를 낮추고, 여유가 생기면 다시 올립니다.
- 그림자·안티앨리어싱·밉맵 없음, 청크 단위 절두체 컬링, 렌더 거리 밖 엔티티는 그리지 않음.
- **높이 256이어도 가볍게**: 청크마다 가장 높은 블록을 기억해 메시 생성·무작위 틱·데이터 복사를 그 높이까지만 합니다(빈 하늘은 건너뜀).
- **리소스 팩**: PNG를 빌드 때 원시 RGBA로 바꿔 압축해 두고, 실행 시 브라우저 내장 `DecompressionStream`으로 풀어 바로 텍스처에 씁니다(캔버스 읽기 없음). 물·용암·차원문 애니메이션은 아틀라스의 해당 칸만 GPU에서 교체합니다.
- **구조물 생성도 워커에서**: 마을·요새·네더 요새는 시드만으로 결정되는 함수라 청크마다 자기 부분만 찍고, 네더 지형은 4×8×4 격자 노이즈를 보간해 계산량을 줄였습니다.
- **레드스톤**: 가루 회로는 변경이 생긴 연결망만 다시 계산하고, 지연 부품은 예약 틱으로 처리합니다.
- **길찾기 예산**: A\* 탐색은 틱당 2회, 탐색 노드 360개로 제한하고 경로를 재사용합니다.
- **몹 한 마리 = 그리기 1~3번**: 몹 모델을 부위마다 따로 그리지 않고 뼈(skinning) 하나의 메시로 합쳐, 엔더 드래곤도 그리기 호출 40번 → 2번이 되었습니다.
- **저장은 워커에서**: 청크 저장(RLE 압축)을 별도 워커에서 처리해 자동 저장·청크 언로드가 프레임을 멈추지 않습니다.
- **셰이더 미리 컴파일**: 로딩 화면에서 모든 몹 모델과 셰이더를 미리 만들어 처음 보는 몹이 등장할 때 멈칫하지 않습니다.
- 잎 소멸 검사·빛 이어붙이기·메시 버퍼를 할당 없이 처리하고, FPS가 낮을 때는 프레임당 GPU 업로드 수를 줄입니다.
- 권장 설정(크롬북): 렌더 거리 4~6, 그래픽 *빠르게*, 자동 해상도 *켜짐*.

## 원작과 다른 점

- 요새는 원작(첫 고리 1280~2816블록)보다 가까운 700~1200블록 고리에 3개 생성됩니다.
- 삼림 대저택·해저 신전·보루 잔해는 원작의 조각(템플릿) 배치 대신 단순화된 절차적 배치로 만들고, 네더 구조물은 y≈32 근처에 고정해서 생성합니다.
- 색·재질은 블록 메타데이터에 담습니다(게임 안에서는 별개 블록처럼 보입니다). 블록 ID를 16비트로 늘리기 전에 들어간 피뢰침·무색 양초는 사슬의 변형, 염색한 양초는 카펫의 남는 메타 비트에 그대로 있습니다. 저장 파일에 아이템 ID 표를 함께 기록해서, 아이템이 추가되거나 순서가 바뀌어도 예전 세계의 인벤토리·상자가 그대로 열립니다(8비트 시절 세계도 불러올 수 있음).
- 무성한 동굴은 1.17에서는 실험용 데이터 팩에서만 생성되지만, 여기서는 y 22~48의 동굴에 자연 생성됩니다.
- 마을 판정은 48블록 안의 종이나 침대로만 합니다(원작의 침대 점유·주민 직업 블록 판정은 없음).
- 판다의 성격은 주 유전자 하나로만 정해지고(열성 유전·번식 유전 없음), 앵무새는 플레이어가 점프해 내려올 때 어깨에 앉습니다. 좀비 말은 원작처럼 명령어로만 나옵니다.
- 폭죽의 잔상(fade)은 색이 바뀌는 대신 두 번째 불꽃으로 표현됩니다.
- 끈으로 동물을 끈 채로 그 동물이 있는 청크에서 멀어지면 끈이 끊어집니다.
- 서 있는 표지판은 네 방향으로만 섭니다(원작은 16방향).
- 블록·아이템·몹 텍스처는 리소스 팩 Pixel Perfection CE(1.16.2 지원)에서 가져옵니다. 팩에 없는 1.17 콘텐츠(구리·자수정·점적석·심층암·양초·무성한 동굴 식물·스컬크 감지기, 염소·아홀로틀·발광 오징어, 망원경 등)와 드래곤 머리·종 몸통 같은 일부만 직접 그린 텍스처를 씁니다. 말 갑옷과 라마 카펫은 원작처럼 겹쳐 그린 별도 모델 대신 몸 텍스처 위에 칠해집니다.
