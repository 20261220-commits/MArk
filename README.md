# 네모 대륙 1.17

마인크래프트 자바 에디션 1.17(동굴과 절벽 1부)을 최대한 비슷하게 따라 만든 브라우저 복셀 샌드박스 게임입니다.
설치 없이 크롬(크롬북 포함)에서 바로 실행되며, 텍스처·아이콘·소리까지 모두 코드로 그려서 외부 리소스가 필요 없습니다.

> Mojang/Microsoft와 관계없는 비공식 팬 프로젝트입니다. 원작의 텍스처·소리 파일은 사용하지 않았습니다.

## 실행 방법

| 방법 | 설명 |
| --- | --- |
| **파일 하나로 실행 (오프라인)** | `dist/nemo-1.17.html` 을 내려받아 크롬에서 열면 됩니다. 인터넷이 없어도 동작합니다. |
| **GitHub Pages** | 저장소 설정 → Pages 에서 `main` 브랜치 루트를 켜면 `index.html` 로 바로 플레이할 수 있습니다. |
| **로컬 서버** | `python3 -m http.server` 후 `http://localhost:8000` 접속 |

세계는 브라우저의 IndexedDB에 저장되므로 같은 브라우저에서 이어서 플레이할 수 있습니다.

## 1.17과 같은 부분

**세계 생성**
- 시드 기반 무한 세계(청크 16×16), 해수면 62, 기반암 층
- 바이옴 13종: 평원, 숲, 자작나무 숲, 타이가, 눈 덮인 타이가/툰드라, 사막, 산, 해변, 강, 늪, 바다, 얼어붙은 바다 — 바이옴별 잔디·나뭇잎·물 색 혼합
- 1.17 방식의 벌레 굴 동굴(carver)과 협곡, y≤10의 용암 호수
- 1.17 광석 분포: 석탄·철·구리(1.17)·금·레드스톤·다이아몬드·청금석·에메랄드(산), 화강암/섬록암/안산암/응회암 덩어리, 흙·자갈 덩어리
- 심층암과 심층암 광석, **자수정 정동**(매끄러운 현무암·방해석·자수정·싹트는 자수정), 점적석
- 던전(몬스터 생성기 + 전리품 상자), 참나무·자작나무·가문비나무, 꽃·풀·고사리·사탕수수·선인장·호박·버섯·마른 덤불, 추운 바이옴의 눈과 얼음

**블록 112종 · 아이템 150여 종**
- 1.17 블록: 구리 블록(산화 4단계, 도끼로 벗기기), 깎인 구리, 원석 블록, 자수정, 방해석, 응회암, 심층암, 점적석, 이끼 블록, 색유리, 가루눈
- 1.17 아이템: 철/금/구리 원석(광석을 캐면 원석이 나옴), 구리 주괴, 자수정 조각, **망원경**(우클릭으로 확대), 가루눈 양동이
- 도구 5재질 × 5종(검·곡괭이·도끼·삽·괭이), 갑옷 4재질 × 4부위, 활과 화살, 가위, 부싯돌과 부시, 양동이(물·용암·우유), 음식 다수

**시스템**
- 자바판 물리 상수(20틱/초, 중력 0.08, 점프 0.42, 달리기 점프, 웅크리면 모서리에서 안 떨어짐, 사다리, 거미줄, 얼음 미끄러짐)
- 채굴 시간 공식(경도·도구 속도·채집 가능 여부·공중/물속 감속)과 도구 내구도
- 1.9 이후 전투: 공격 쿨다운, 치명타, 넉백, 갑옷 방어 공식
- 체력·허기·포화도·탈진, 자연 회복과 굶주림, 낙하/익사/용암/화염/질식/선인장 피해, 경험치와 레벨
- 2×2/3×3 제작(모양·무형 레시피, 좌우 반전), 화로 제련(연료 시간·경험치), 상자, 침대(밤 넘기기·리스폰 지점), 문, 반 블록, 사다리, 횃불(벽 부착)
- 인벤토리 조작: Shift+클릭, 우클릭 절반, 드래그 나누기, 숫자키 교체, 더블클릭 모으기, Q 버리기
- 몹: 좀비·스켈레톤(활)·크리퍼(폭발)·거미, 돼지·소(우유)·양(털 깎기)·닭(달걀)·염소(1.17) — 번식, 유혹, 햇빛에 타는 언데드, 어둠 속 스폰
- 물/용암 흐름(근원·흐름 단계, 무한 수원, 흑요석·조약돌 생성), 모래·자갈 낙하, TNT 연쇄 폭발
- 무작위 틱: 작물 성장, 묘목→나무, 잔디 번짐, 나뭇잎 소멸, 경작지 수분, 구리 산화, 자수정 성장
- 낮/밤(20분), 해·달·별, 노을, 구름, 비/눈, 날씨 변화
- 게임 모드: 서바이벌, 크리에이티브(비행·즉시 파괴·검색되는 아이템 목록), 하드코어, 관전자
- 명령어: `/gamemode` `/time` `/weather` `/give` `/tp` `/summon` `/kill` `/seed` `/difficulty` `/xp` `/spawnpoint` `/clear`
- F3 디버그 화면, F5 3인칭, F1 HUD 숨기기

## 크롬북 최적화

- **Web Worker 멀티스레드**: 지형 생성과 메시 생성을 모두 워커(코어 수에 맞춰 1~3개)에서 처리해 메인 스레드가 끊기지 않습니다.
- **동굴 경로 캐시**: 청크마다 주변 289개 청크의 동굴을 다시 계산하지 않고 한 번 계산한 경로를 재사용합니다 (청크 생성 67ms → 17ms).
- **메셔**: 숨은 면 제거, 위아래까지 패딩한 볼륨에서 인덱스 오프셋으로 이웃·AO를 읽어 청크당 약 5ms.
- **작은 정점 형식**: 정점당 20바이트(Uint16 위치/UV, Uint8 빛/색). 바이옴 색은 텍스처 알파 마스크로 셰이더에서 입혀 텍스처를 늘리지 않습니다.
- **프레임 예산**: 워커 결과는 한 프레임에 쓰는 시간과 GPU 업로드 수를 제한해서 반영하고, 워커는 프레임과 상관없이 계속 일을 받습니다.
- **자동 해상도**: FPS가 40 아래로 떨어지면 렌더 해상도를 낮추고, 여유가 생기면 다시 올립니다.
- 그림자·안티앨리어싱·밉맵 없음, 청크 단위 절두체 컬링, 렌더 거리 밖 엔티티는 그리지 않음.
- 권장 설정(크롬북): 렌더 거리 4~6, 그래픽 *빠르게*, 자동 해상도 *켜짐*.

## 원작과 다른 점

- 세계 높이는 0~127입니다(1.17은 0~255). 크롬북 메모리를 아끼기 위한 선택입니다.
- 네더·엔드, 레드스톤 회로, 마법 부여, 마을은 없습니다.
- 몹은 길찾기 대신 직선 추적 + 점프로 움직입니다.

## 조작

| 키 | 동작 |
| --- | --- |
| W A S D | 이동 (W 두 번 / R / Ctrl: 달리기 — 크롬북에서 Ctrl+W는 탭을 닫으니 R 권장) |
| Space | 점프·수영 (크리에이티브: 두 번 눌러 비행) |
| Shift | 웅크리기 / 비행 중 하강 |
| 좌클릭 | 캐기·공격 |
| 우클릭 | 놓기·사용·먹기·활·망원경 |
| 휠 클릭 | 블록 고르기 |
| 1~9 / 휠 | 단축바 |
| E | 인벤토리 |
| Q | 버리기 (Ctrl+Q 묶음) |
| T, / | 채팅, 명령어 |
| F1·H / F3·\` / F5·V | HUD 숨기기 / 디버그 / 시점 (F키가 없는 크롬북용 대체 키) |

터치 화면에서는 왼쪽 조이스틱, 화면 드래그로 시점, 오른쪽 버튼(캐기·놓기·점프·웅크리기)을 사용합니다.

## 구조

```
index.html          화면 구성과 스타일
js/shared.js        블록 정의, 노이즈, 지형 생성, 조명, 메셔 (워커와 공유)
js/items.js         아이템, 제작법, 제련, 드롭
js/textures.js      절차적 텍스처 아틀라스와 아이콘
js/world.js         청크 스트리밍, 조명 전파, 블록 업데이트, 유체, 저장(IndexedDB)
js/render.js        three.js 렌더링, 하늘, 파티클, 비, 손
js/entities.js      몹, 아이템, 화살, TNT, 폭발
js/player.js        플레이어 물리, 생존 수치, 상호작용
js/inventory.js     인벤토리와 컨테이너 클릭 규칙
js/ui.js            메뉴, HUD, 채팅·명령어
js/main.js          메인 루프, 입력, 세계 불러오기/저장
tools/build.js      dist/nemo-1.17.html 단일 파일 빌드
```

`node tools/build.js` 로 단일 파일을 다시 만들 수 있습니다.
